## Version 1.0.4
- Completely reworked how random values are retrieved internally, allowing for more unique interaction in the future. Keep an eye out for v1.1.0!
- Semi-Automated Doll (White)'s barrier no longer triggers against non attack damage (e.g. Giant Scissor Blade).
- Fixed Cirno's Plan Semi-Automated Doll (White), and Semi-Automated Doll (Black) not working with Chaos! and Order.
- Fixed Reverse Hiearchy not properly using the count variable to determine if a card will be upgraded.
- Slightly changed the wording on Luck and Luck Down.
- Changed White Rabbit Luck's effect: Exile is no longer in the default list of zones. Instead, playing from Exile is now a 20% chance to occur.
- The Firepower gain from Poverty God's Wrath is now gained as soon as a percent fails, as opposed to the start of the next turn.
- Changed Black Market Kaleidoscope's effect: Generated cards no longer have a chance to cost 0 mana. Instead, mana of any color can be spent to pay their cost, which is reduced by 3.

## Version 1.0.3
- Fixed a bug where Semi-Automated Doll (White) would softlock when trying to react to the Apex Speedster status.
- Added Meteonic Debris to the pool of tokens that can be generated by Semi-Automated Doll (Blue).

## Version 1.0.2
